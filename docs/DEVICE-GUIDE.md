# Device guide — EASYTONE / G10 air mouse on Windows

**Product link:** [Amazon B08DFDNZCV](https://www.amazon.com/dp/B08DFDNZCV)

## Two roles, one remote

1. **Mouse + keyboard** — works with Windows immediately via the USB dongle.  
2. **Mic + MIC button** — mic may show as a Windows input device; the **button** needs Air Mouse Remote to trigger **Win+H**.

## Dictation

1. Run **Air Mouse Remote** (taskbar + tray).  
2. Click a text field.  
3. Press **MIC**.  
4. Speak into the remote’s mic hole.

## Center button = click vs Enter

| Air mouse | Center button |
|-----------|----------------|
| Unlocked (wave to move cursor) | **Click** |
| Locked (mouse on/off) | **Enter** |

Lock before you expect Enter to send a message.
